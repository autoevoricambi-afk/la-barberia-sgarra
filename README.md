# La Barberia Sgarra

Sito premium mobile-first per La Barberia Sgarra: servizi, gallery tagli e prenotazione appuntamenti.

## Stato operativo

- Frontend pubblico collegato a Vercel.
- Prenotazione con Paolo Sgarra e Giuseppe.
- Hero premium aggiornata con asset ottimizzati.
- Notifiche automatiche disattivate in modo silenzioso finché non vengono configurati email/webhook.
- Deploy finale forzato dopo sostituzione asset hero.
- Marker finale: verificare dopo il deploy Vercel.
- Binary hero assets updated.

## Deploy

Il progetto è collegato a GitHub e Vercel. Ogni push su `main` genera un deploy automatico.

## Note

Durante il collaudo il sito resta `noindex, nofollow`. Il dominio definitivo previsto è `labarberiasgarra.it`.
